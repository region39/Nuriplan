# План реализации: Модуль интеграции с Telegram и обратная связь для пользователей

## 1. Описание задачи и цели
Реализовать систему прямой обратной связи от авторизованных пользователей к администратору через Telegram:
- **Для администратора (в разделе «Настройки»):** закрытый модуль настройки канала связи Telegram (ручной ввод `Bot Token` и `Chat ID`, проверка соединения тестовым сообщением, краткая памятка по подключению бота и контактные данные для отображения пользователям). Для обычных пользователей этот блок полностью скрыт.
- **Для авторизованных пользователей (отдельная вкладка «Обратная связь» в верхнем меню):** удобное окно в формате чата/формы обращения, откуда каждое отправленное сообщение мгновенно пересылается в подключенный Telegram-чат или бот администратора, а также сохраняется в истории отправленных обращений пользователя.

---

## 2. Изменения на сервере и в базе данных (`server.ts`)

1. **Таблица истории обращений `feedback_messages`:**
   - Создание таблицы `feedback_messages` (`id`, `user_id`, `username`, `topic`, `contact_info`, `message`, `telegram_sent`, `created_at`).
2. **Защита настроек Telegram:**
   - Хранение `telegram_bot_token`, `telegram_chat_id` и `admin_contact_note` в таблице `settings`, но исключение секретного `telegram_bot_token` из публичного ответа `GET /api/settings`.
3. **API управления интеграцией Telegram (только для `admin` через `requireAdmin`):**
   - `GET /api/admin/telegram` — получение текущих настроек (`botToken`, `chatId`, `contactNote`, статус активности).
   - `POST /api/admin/telegram` — сохранение `botToken`, `chatId` и `contactNote`.
   - `POST /api/admin/telegram/test` — отправка тестового сообщения через Telegram Bot API (`https://api.telegram.org/bot<TOKEN>/sendMessage`) для проверки корректности токена и `Chat ID`.
4. **API отправки и просмотра обращений (`Feedback API`):**
   - `POST /api/feedback` (для любого авторизованного пользователя) — сохраняет сообщение в БД и отправляет отформатированное уведомление в Telegram администратору (с указанием логина автора, темы, контакта для связи и текста сообщения).
   - `GET /api/feedback` — возвращает пользователю историю его собственных отправленных сообщений (а администратору — полный список всех обращений пользователей).

## 3. Изменения в клиентском интерфейсе (`src/`)

1. **Модуль интеграции с Telegram в настройках (`src/components/SettingsView.tsx`):**
   - Передача `userRole` в `SettingsView`.
   - Отображение карточки **«Интеграция с Telegram (Канал связи администратора)»** строго для `userRole === 'admin'`:
     - Поля ввода `Telegram Bot Token` (с возможностью скрыть/показать символы) и `Telegram Chat ID`.
     - Поле дополнительной информации/контактов для пользователей (например, часы ответа или резервный контакт).
     - Кнопки **«Сохранить настройки»** и **«Тестовое сообщение в Telegram»** с мгновенной индикацией результата.
     - Краткая встроенная инструкция: как получить токен у `@BotFather` и узнать `Chat ID` своего аккаунта или рабочей группы.
2. **Новая вкладка «Обратная связь» (`src/components/FeedbackView.tsx` и `src/App.tsx`):**
   - Добавление пункта **«Обратная связь»** с иконкой чата в верхнюю панель навигации (`App.tsx`) для всех авторизованных пользователей.
   - Интерфейс в стиле окна чата с администратором:
     - Лента ранее отправленных пользователем сообщений с отметкой времени и статусом доставки.
     - Выбор темы обращения (Вопрос по работе сервиса, Предложение по функционалу, Сообщение об ошибке, Другое), необязательное поле «Куда вам ответить (Telegram / Телефон / Email)» и поле ввода текста сообщения.
     - Для роли `admin` на этой же вкладке доступен переключатель просмотра всех входящих обращений от пользователей со статусом доставки в Telegram.
